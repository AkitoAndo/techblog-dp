# 動的プライシングシステム（改善版）

このプロジェクトは、正則化、可視化の改善、エラーハンドリングを追加した動的プライシングシステムの実装です。

## セットアップ

### 必要なパッケージのインストール

```bash
pip install -r requirements.txt
```

または

```bash
uv add pandas numpy scikit-learn matplotlib
```

## 実行方法

```bash
python dynamic_pricing_improved.py
```

## 主な機能

1. **データ生成**: 過去90日分の販売データをシミュレート
2. **需要予測モデル**: Ridge回帰を使用した正則化付きモデル
3. **最適価格計算**: 収益を最大化する価格を計算
4. **在庫考慮**: 在庫状況に応じた価格調整
5. **時間帯考慮**: 曜日や時間帯に応じた価格調整
6. **可視化**: 価格と需要・収益の関係、残差プロット、予測精度の可視化

## 改善点

前回の実装（01プロジェクト）と比較して、以下の改善を行いました：

- **データ量の増加**: 30日分から90日分に増加
- **正則化の導入**: Ridge回帰により過学習を抑制
- **可視化の改善**: 残差プロットと予測精度の可視化を追加
- **エラーハンドリング**: 無効な入力値に対するエラーハンドリングを追加

## 出力

実行すると、以下の情報が表示されます：

- 学習データと検証データでの予測精度（R²、MAE、RMSE）
- 最適価格とその時の予測需要・収益
- 在庫や時間帯を考慮した価格調整の結果
- 可視化結果（`pricing_analysis_improved.png`）

## 注意事項

- この実装は教育目的のシミュレーションデータを使用しています
- 実際のビジネスに適用する場合は、実データを使用し、A/Bテストを実施してください
