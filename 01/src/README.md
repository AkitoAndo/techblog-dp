# 動的プライシング実装

このディレクトリには、動的プライシングシステムの実装コードが含まれています。

## セットアップ

必要なパッケージをインストールします：

```bash
pip install -r requirements.txt
```

または、`uv`を使用する場合：

```bash
uv pip install -r requirements.txt
```

## 実行方法

メインスクリプトを実行します：

```bash
python dynamic_pricing.py
```

## 実行内容

スクリプトは以下の処理を実行します：

1. **過去の販売データの生成**: 30日分のシミュレーションデータを生成
2. **需要予測モデルの構築**: 学習データと検証データに分割してモデルを学習し、精度を評価
3. **最適価格の計算**: 収益を最大化する価格を計算
4. **在庫を考慮した価格調整**: 在庫状況に応じた価格調整の例
5. **時間帯を考慮した価格調整**: 曜日や時間帯に応じた価格調整の例
6. **可視化**: 価格と需要、収益の関係をグラフで可視化（`pricing_analysis.png`として保存）

## 出力ファイル

- `pricing_analysis.png`: 価格と需要、収益の関係を可視化したグラフ

## 注意事項

- データはランダムシード（42）を使用して生成されているため、再現可能です
- 検証データでの精度が低い場合は、過学習の警告が表示されます
- グラフの日本語表示には、システムに適切な日本語フォントが必要です
